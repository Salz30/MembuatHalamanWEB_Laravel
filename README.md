# Sistem Bimbingan Konseling (Sikonsel) - SMPN 4 Rancaekek 🏫

Proyek ini adalah sebuah halaman web statis yang dikembangkan menggunakan framework Laravel dan Bootstrap 5. Proyek ini dibuat untuk memenuhi tugas mata kuliah **Pemrograman Web 2** (Pertemuan 5: Membuat Halaman Web Statis).

Portal bimbingan konseling ini dirancang dengan antarmuka yang modern, responsif, dan menenangkan untuk membantu siswa dalam mendapatkan informasi seputar layanan Bimbingan dan Konseling (BK), profil konselor, serta panduan akademik.
